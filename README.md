# PlateFit (প্লেটফিট) 🏍️🇧🇩

**Precision BRTA Number Plate Generator, Creative Custom Studio & Road Safety Handbook for Bangladesh**

---

## 📌 Overview
**PlateFit** is a mobile-first, privacy-focused web application and PWA designed to help motorcyclists, scooterists, and vehicle owners in Bangladesh:
1. **BRTA 1:1 Scale Stencil Mode:** Prepare exact physical dimension front plates adhering to official BRTA mandates ($285\text{ mm} \times 50\text{ mm}$ for bikes, $200\text{ mm} \times 100\text{ mm}$ for scooters) and export vector print-ready PDFs at 100% scale.
2. **Creative Custom Plate Studio:** Design custom, decorative, or track/show plates with carbon fiber textures, matte black, neon themes, emergency blood group badges, club logos, and custom typography.
3. **Road Transport Act 2018 & Highway Rules:** Searchable penalties, fine matrix, national speed limits, and defensive riding guidelines.
4. **Local Fabricator Directory:** Direct one-click WhatsApp quote requests to verified local metal fabricators and laser cut acrylic shops across Bangladesh.

---

## 🚀 Tech Stack
- **Framework:** Next.js (App Router), React
- **Styling:** Tailwind CSS v4, Lucide React, Glassmorphism design tokens
- **Vector Engine:** 1:1 Millimeter-accurate SVG & `jspdf` vector rendering
- **Typography:** SolaimanLipi, Tiro Bangla, Hind Siliguri, Noto Sans Bengali
- **Privacy:** 100% Client-side. Zero server logging or storage of vehicle registrations.

---

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## ⚖️ Legal Disclaimer
PlateFit is an independent community utility tool and is not affiliated with or endorsed by the BRTA or the Government of Bangladesh. Front plates generated with this tool serve as measurement stencils for physical metal fabrication. Custom/Decorative plates are strictly for off-road or display use. Official rear digital/RFID plates issued by BRTA cannot and should not be replaced.
